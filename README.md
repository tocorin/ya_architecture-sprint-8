# Приложение 

Приложение позволяет авторизоваться через Keycloak 

## Запуск приложения

Выполнить комаду

   ```
   docker-compose up -d
   ```

## Замечания
При первом запуске `docker-compose` иногда keycloak отказывается запускаться самостоятельно.
Кажется, что пытается подключиться к бд, а она еще не конекты не принимает.

проверить сервисов можно командой:
```bash
   docker compose ps --format "{{.Service}} {{.State}}"
```

запустить отдельный сервис:
```bash
   docker-compose start keycloak  
```
